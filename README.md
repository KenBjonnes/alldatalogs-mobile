# BigData for Android and iPhone

The AllDataLogs datalog viewer as a native phone/tablet app (Capacitor 8). Free tier opens logs up to the
free cap; signing in with an AllDataLogs Pro account unlocks the Pro caps and features. Pro is bought on
alldatalogs.com, never in the app.

## Layout

| Path | What |
|---|---|
| `www/` | the web app the native shells load — GENERATED by `scripts/build-payload.mjs`, committed, hash-checked in CI |
| `src/` | TypeScript glue (`glue.ts`), licensing (`license.ts` pure decision + `licensing.ts` runtime), Supabase, native plugin wrappers, file paths, caps |
| `scripts/` | payload builder, static dev server (`npm run web`), Playwright smoke (`npm run smoke:web`) |
| `test/` | node:test suites (licence state machine, caps) |
| `android/`, `ios/` | the native projects (`npx cap add …`), built only in CI |

## Working on it

```
npm ci
npm approve-scripts esbuild sharp && npm rebuild esbuild sharp
node scripts/build-payload.mjs        # needs the engine RELEASE folder + the Alldatalogs repo (Ken's PC)
npm test
npm run web                           # http://localhost:5174/?devpro=1 — use DevTools' device toolbar at 916x412
npm run smoke:web
```

The engine files come from `C:\Users\kenbj\Code\datalog viewer` (the work folder's `release.ps1` output) and
the shared TypeScript (`viewerPayload.ts`, `_shared/jws.ts`, the decoder) from `C:\websites\Alldatalogs`,
so the app can never drift from what the website runs. `BIGDATA_RELEASE_DIR` / `BIGDATA_SITE_REPO`
override the paths.

## Licensing

Same signed entitlement token as BigData for Windows (`issue-entitlement-token`, audience
`bigdata-mobile`), verified on the device with the embedded public key; the token's lifetime is the
offline grace period. See `src/license.ts` for the state machine and `test/license.test.js` for every case.
